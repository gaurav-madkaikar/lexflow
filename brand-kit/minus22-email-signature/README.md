# Minus22 email signature kit

This kit uses the same typography stack as LexFlow: **Avenir Next, Helvetica Neue, Inter, Arial, sans-serif**. The M22 mark is an original Minus22 monogram, while the rounded geometry, neutral ink color, and coral accent keep it in the same brand family.

## Included

- `signature-light.html` — full signature with contact details, tagline, and confidentiality line.
- `signature-compact.html` — compact reply and mobile-friendly signature.
- `logos/minus22-logo-email.png` — email-safe PNG mark at 2× resolution.
- `logos/minus22-lockup-dark.svg` — editable lockup for light backgrounds.
- `logos/minus22-lockup-reversed.svg` — editable lockup for dark backgrounds.
- `preview/minus22-signature-preview.png` — visual preview of both formats.

## Set up

1. Replace every bracketed field and the example contact information in the HTML.
2. Host `minus22-logo-email.png` on the company website or an approved public asset host.
3. Replace the relative image source with its absolute HTTPS address.
4. Open the HTML in a browser, select the rendered signature, copy it, and paste it into the Gmail or Outlook signature editor.
5. Send test messages to Gmail, Outlook desktop, Outlook web, iPhone Mail, and Android before rollout.

The included domain, phone number, location, tagline, and confidentiality wording are editable placeholders. Confirm them before deployment.
