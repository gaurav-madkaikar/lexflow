# LexFlow launch asset pack

Ready-to-post PNGs are in `png/`; editable master artwork is in `svg/`. Copy, alt text, and usage notes are in `LAUNCH-COPY.md`.

## Formats
- Launch hero: 1920 x 1080
- LinkedIn post: 1200 x 627
- X post: 1600 x 900
- Instagram post: 1080 x 1080
- Instagram story: 1080 x 1920
- LinkedIn company banner: 1128 x 191
- Product launch tile: 1200 x 1200

This pack follows LexFlow Brand Kit v1.0. It contains no customer data, invented URLs, launch dates, or unsupported product claims.
